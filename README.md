# Linktree

Basicamente es mi linktree, mi idea fue crear algo útil, sencillo de usar y con una estructura que pudiera seguir mejorando con el tiempo.

## Sobre el proyecto

Empecé este proyecto para poder tener acceso a mis links e información personal de forma rápida y ágil.

Además de llegar a un resultado funcional, quise aprovecharlo para practicar diseño web tanto como con HTML, CSS y Javascript, así para también poder tomar decisiones propias durante el desarrollo.

## Funcionalidades

- Presentar y dar información con el uso de botones de manera simple y consisa.

## Tecnologías

- HTML, CSS y Javascript
- Codeado en VSCode
